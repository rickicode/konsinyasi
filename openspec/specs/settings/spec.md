> Generated by openlore v1.0.0 on 2026-07-26 01:44

## Purpose

Manages application-wide configuration settings, specifically the server base URL, including
persistence, validation, and runtime application with dependency invalidation.

## Entities

### GeofenceSettings

> `src/shared/schemas/settings.schema.ts`

Represents the configurable geofence parameters that define a geographic boundary for location-based
operations.

**Properties:**

| Name              | Type   | Description                                              |
| ----------------- | ------ | -------------------------------------------------------- |
| geofence_radius_m | number | Radius of the geofence boundary in meters                |
| brand_name        | string | Display name of the brand associated with these settings |
| logo_url          | string | null                                                     | Optional URL to the brand logo image |
