## Entities

### RawMaterial

> `src/shared/schemas/raw-material.schema.ts`

Represents a raw material or ingredient used in production, with its base unit of measurement and
pricing per unit.

**Properties:**

| Name                | Type     | Description                                       |
| ------------------- | -------- | ------------------------------------------------- |
| id                  | string   | Unique identifier                                 |
| name                | string   | Name of the raw material                          |
| base_unit           | BaseUnit | Base unit of measurement (e.g., kg, liter, piece) |
| price_per_base_unit | number   | Price per base unit in integer currency units     |
| created_at          | string   | Creation timestamp in ISO string format           |
| updated_at          | string   | Last update timestamp in ISO string format        |

## Requirements

### Requirement: RawMaterialValidation

The system SHALL validate RawMaterial according to these rules:

- Name is required and must be at least 1 character
- Price per base unit must be an integer
- Price per base unit must be non-negative
- Price per base unit must be a number type
