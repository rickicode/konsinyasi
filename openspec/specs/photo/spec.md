## Purpose

Manages photo file operations including key generation, validation, extraction from form data,
upload to R2 storage, and safe deletion with namespace guards.

## Entities

### Photo

> `src/web/lib/photo.ts`

Represents a photo file with associated metadata and processing capabilities

**Properties:**

| Name    | Type   | Description                               |
| ------- | ------ | ----------------------------------------- |
| file    | File   | The raw image file data                   |
| maxEdge | number | Maximum edge dimension for resizing       |
| quality | number | JPEG compression quality (0-1)            |
| type    | string | Output MIME type for the compressed image |

## Requirements

### Requirement: PhotoValidation

The system SHALL validate Photo according to these rules:

- maxEdge must be a positive number
- quality must be between 0 and 1
- type must be a valid image MIME type
- Input file must be a valid image decodable by createImageBitmap

#### Scenario: CompressOversizedPhoto

- **GIVEN** A photo file exceeding maximum edge dimensions
- **WHEN** compressPhoto is called with maxEdge=1600
- **THEN** A compressed Blob is produced with dimensions within constraints
- **AND** Image dimensions are constrained to maxEdge on longest side
- **AND** Output is encoded as image/jpeg with specified quality

#### Scenario: CompressPhotoWithResourceCleanup

- **GIVEN** A valid image file
- **WHEN** compressPhoto completes processing
- **THEN** Compressed image is returned and all intermediate resources are freed
- **AND** Bitmap resources are released via bitmap.close()
- **AND** Canvas context is cleaned up
