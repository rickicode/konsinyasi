## Entities

### User

> `src/shared/schemas/user.schema.ts`

Represents a registered user in the system with authentication credentials and role-based access
control.

**Properties:**

| Name       | Type       | Description                                     |
| ---------- | ---------- | ----------------------------------------------- |
| id         | string     | Unique identifier for the user                  |
| email      | string     | Email address used for login and communications |
| username   | string     | Unique username for identification              |
| name       | string     | Display name of the user                        |
| role       | UserRole   | Role determining access level: staff or owner   |
| status     | UserStatus | Account status: active or inactive              |
| created_at | string     | ISO timestamp of when the user was created      |
| updated_at | string     | ISO timestamp of last update                    |

## Requirements

### Requirement: UserValidation

The system SHALL validate User according to these rules:

- Name is required (minimum 1 character)
- Email must be valid format
- Username must be at least 3 characters
- Password must be at least 6 characters
- Role must be either 'staff' or 'owner'
- Status must be either 'active' or 'inactive'
- Role defaults to 'staff' on creation if not specified
