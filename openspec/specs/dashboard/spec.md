# Dashboard Specification

> Generated by openlore v1.0.0 on 2026-07-26 01:44

## Purpose

Encapsulates dashboard data access layer, providing raw API fetching and TanStack Query integration
for reactive dashboard state management.

## Requirements

> `src/web/features/dashboard/api/index.ts`

### Requirement: FetchDashboard

> Implementation: `fetchDashboard` in `src/web/features/dashboard/api/index.ts` · confidence: llm

The system SHALL retrieve the complete dashboard report from the backend api endpoint `/api/dashboard/`.

#### Scenario: SuccessfulDashboardReportRetrieval

<!-- openlore-test: tags=smoke (auto) -->

- **GIVEN** API client is available and backend is reachable
- **WHEN** fetchDashboard is called
- **THEN** Returns parsed DashboardReport object
- **AND** Response body validated against dashboardReportSchema

#### Scenario: FailedDashboardReportRetrieval

<!-- openlore-test: tags=regression (auto) -->

- **GIVEN** Backend returns non-2xx status or invalid response body
- **WHEN** fetchDashboard is called
- **THEN** Throws error with failure details
- **AND** Error propagates to caller

### Requirement: DashboardQueryOptions

> Implementation: `dashboardQueryOptions` in `src/web/features/dashboard/api/index.ts` · confidence: llm

The system SHALL construct tanstack query options for dashboard data fetching with 30-second stale time.

#### Scenario: QueryOptionsFactoryProducesValidConfiguration

<!-- openlore-test: tags=smoke (auto) -->

- **GIVEN** Query keys are configured for dashboard domain
- **WHEN** dashboardQueryOptions is called
- **THEN** Returns queryOptions object with dashboard query key and fetchDashboard as query function
- **AND** queryFn wraps fetchDashboard with provided client
- **AND** staleTime set to 30000ms
