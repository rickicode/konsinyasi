## Purpose

Manages the reactive state for a list of products, including loading from repository and client-side
filtering by name.

## Entities

### Product

> `src/shared/schemas/product.schema.ts`

A manufactured or sellable item in the business domain, with optional recipe-based raw material
composition and configurable pricing.

**Properties:**

| Name            | Type          | Description                                        |
| --------------- | ------------- | -------------------------------------------------- |
| id              | string        | Unique identifier                                  |
| name            | string        | Product display name                               |
| status          | ProductStatus | Current lifecycle state - active or inactive       |
| hpp             | number        | Computed production cost based on recipe materials |
| hpp_override    | number        | null                                               | Manual override for production cost, bypassing recipe calculation |
| price_to_outlet | number        | Selling price to outlet/distributor                |
| photo_key       | string        | null                                               | S3/object storage key for product image                           |
| deleted_at      | string        | null                                               | Soft deletion timestamp in ISO format                             |
| created_at      | string        | Record creation timestamp in ISO format            |
| updated_at      | string        | Record last modification timestamp in ISO format   |

**Relationships:**

- has-many RecipeLine (Product optionally contains multiple recipe lines defining raw material composition)
- has-one ProductPhoto (Product photo stored as object reference via photo_key)

### RecipeLine

> `src/shared/schemas/product.schema.ts`

A single line item in a product recipe specifying required raw material, quantity, and unit of
measurement.

**Properties:**

| Name              | Type     | Description                                                            |
| ----------------- | -------- | ---------------------------------------------------------------------- |
| id                | string   | Unique identifier for this recipe line entry                           |
| raw_material_id   | string   | Reference to the raw material entity                                   |
| raw_material_name | string   | Display name of the raw material (denormalized for read efficiency)    |
| base_unit         | BaseUnit | Base unit of measurement for the raw material (e.g., kg, liter, piece) |
| quantity          | number   | Amount of raw material required in production                          |
| unit              | BaseUnit | Unit used for this recipe line quantity                                |

**Relationships:**

- belongs to Product (Recipe line belongs to a specific product composition)
- belongs to RawMaterial (Recipe line references a raw material for inventory tracking)
